# BrandCraft® — Premium Creative Studio Website

A responsive, interactive agency website for BrandCraft (@brandcraft_01).

## How to open

1. Extract the ZIP archive into a folder.
2. Open `index.html` with Chrome, Firefox, Safari or Edge. No build step, development server, npm install or network connection is required. You can also open `BrandCraft_OneClick.html` directly as a standalone all-in-one file.
3. Scroll through the **four interactive concept scenes** to see product/device mockups; click the numbered tabs to navigate directly.
4. Use the `FR / AR` language switch and contact brief form. The brief is copied to the clipboard and Instagram opens in a new browser tab for sending manually.

## Components

- Original real-time WebGL metallic sculpture in the opening scene, rendered without third-party packages.
- Bright, sticky, scroll-driven service/showreel stage.
- Six service categories with original HTML/CSS visual mockups.
- Arabic and French text switcher.
- Responsive mobile navigation, accessible keyboard focus and reduced-motion fallback.
- Contact-brief helper linked to the real BrandCraft Instagram profile.
- 100% local CSS/JS; external link to Instagram only when clicked.
